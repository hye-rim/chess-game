# 체스 ♟️

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 체스. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- **표준 체스 규칙**: 폰·나이트·비숍·룩·퀸·킹의 움직임, 체크·체크메이트·스테일메이트, **캐슬링**(킹·룩이 안 움직였고 사이가 비었고 킹이 체크 중이거나 지나가는 칸이 공격받으면 불가), **앙파상**(킹을 노출시키는 경우 불가), **프로모션**(퀸·룩·비숍·나이트 선택)
- 무승부: 스테일메이트 · 50수 규칙 · 같은 모양 세 번 · 기물 부족(킹만, 킹+비숍/나이트 하나, 같은 색 칸 비숍들만)
- **규칙 검증은 perft 로**: 알려진 시작 판 여섯 개(시작 판·Kiwipete·룩 엔드게임·프로모션 판 둘·대칭 중반)에서 가능한 수의 개수가 정확히 같다. 시험에는 깊이 3~4까지, 따로 시작 판 5단계 4,865,609 · Kiwipete 4단계 4,085,603 · 룩 엔드게임 5단계 674,624 · 프로모션 판 4단계 422,333 · 2,103,487 · 대칭 판 4단계 3,894,594 까지 모두 일치함을 확인
- 화면: 합법인 수만 **점**(잡는 수는 고리)으로 표시, 마지막 수는 노랗게, **상대가 방금 둔 말**은 반짝이는 노란 테두리(출발 칸은 주황 테두리, 내 말이 잡힌 칸은 빨간 테두리), 체크인 킹은 빨갛게, 잡은 말과 점수 차이를 이름표에 표시, 프로모션 선택 창. 검정이면 판이 뒤집혀 내 말이 늘 아래
- 컴퓨터: 쉬움은 30% 는 아무 수나 두고 가끔 근소하게 나쁜 수를 두며 2수 앞을 본다. 어려움은 0.7초 안에서 깊이를 늘려 가며(최대 8수) 알파-베타 탐색(잡는 수 우선·정지 탐색·체크 연장, 말 가치+자리 점수) 한다. 어려움이 쉬움을 이긴다(시험으로 확인). 내 색(흰색·검정)은 제목 화면에서 고른다
- 컴퓨터를 이긴 횟수는 `chessWins` (로비 표시용), 온라인 전적은 `chessOnline`
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 한 수 2분(넘기면 시간패) · 기권 · 한 판 더(흰색·검정 교대). 서버가 같은 규칙(`public/logic.js`)으로 모든 수를 검사한다(차례가 아니거나 규칙에 어긋난 수는 무시). 방 코드를 짧은 시간에 많이 틀리면 잠깐 막는다
- M 소리

규칙과 컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(perft·FEN·캐슬링·앙파상·프로모션·체크메이트·스테일메이트·무승부·컴퓨터), `test/server.test.js`(서버를 띄워 매칭·입력 검사·체크메이트로 끝나는 판·시간 초과·기권·재접속 등).
